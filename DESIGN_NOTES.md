# Design Notes

## Reference Analysis Summary

The reference portfolios shared by the user suggested these useful patterns:

1. Strong hero identity with large name/title.
2. Compact navigation with direct links to key sections.
3. Technical stack grouped into clear categories.
4. Project cards that explain the idea, stack, and impact.
5. Dark theme with strong contrast.
6. Motion used for personality, not random decoration.
7. Contact CTA near the end.
8. Resume/social links visible from the top.

## Unique Direction Used Here

This portfolio combines those ideas into a new layout:

- Hero split layout with scattered role/tech words.
- Premium glass cards.
- Dark + light theme.
- Animated cursor effect.
- Project case-study cards with impact and highlights.
- Editable data-driven content.
- Student + engineer + frontend developer positioning.

## Color Direction

User requested:

- black / grey / white / yellow / red
- dark blue and orange
- dark + light mode
- animated background
- cursor effect
- word scattering
- plain and simple but premium

The implementation uses a black/dark-blue base, muted grey cards, white text, yellow primary, orange accent, and controlled red/blue glows.
